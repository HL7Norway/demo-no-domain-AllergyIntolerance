# Demo AllergyIntolerance Implementation Guide

Dette repositoryet inneholder en demo for en HL7 FHIR implementasjonsguide for AllergyIntolerance. AllergyIntolerance skal basere seg på [HL7 Europe Base and Core FHIR IG R4](https://github.com/hl7-eu/base).

## Referanser og bakgrunnsstoff

- [EHDS Logical Information Models - Logical Model: Allergy intolerance model](https://www.xt-ehr.eu/fhir/models/1.0.0/en/StructureDefinition-EHDSAllergyIntolerance.html)
- [Resource Profile: AllergyIntolerance (EU core)](https://hl7.eu/fhir/base/StructureDefinition-allergyIntolerance-eu-core.html)
- [Helse-NIM for overfølsomhet](https://www.helsedirektoratet.no/veiledere/helse-nim-for-oppsummerende-helseopplysninger/helse-nim-for-overfolsomhet)

## ✨ Hva inneholder demoen?

- **FSH-profiler:** Demo-profiler for `Patient` og `AllergyIntolerance`
- **Automatisk validering:** FSH og SUSHI-validering via GitHub Actions
- **Automatisk publisering:** Bygg og publiser IG til GitHub Pages
- **PlantUML-støtte:** Automatisk generering av diagrammer
